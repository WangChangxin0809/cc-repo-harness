# Code of Conduct

## The standard

Be straightforward and be kind. Disagree with the argument, not the person.
Assume the other party read the thing and reached a different conclusion.

This project is largely an argument about what fails silently in software, so
disagreement is the normal mode here and it is welcome. What is not welcome is
harassment, personal attacks, demeaning comments, publishing someone's private
information, or persistently pushing past a clear "no".

## Scope

Applies in this repository — issues, pull requests, discussions, commit
messages, and code comments — and in any space where someone is representing
this project.

## Enforcement

Report to the maintainer, privately, via a
[private security advisory](../../security/advisories/new) if it involves
anything sensitive, or by email otherwise.

Reports are handled privately. The maintainer may remove comments, close a
thread, or block an account. If you disagree with a decision, say so — in
private, once. Persisting in public is itself covered by the section above.

Adapted from the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, shortened to what this project can actually commit to enforcing.
A code of conduct promising a process nobody runs is worse than a short one that
is kept.
