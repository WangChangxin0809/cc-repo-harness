# A person reads these once, and then closes them

Everything else in this repository is read by an agent, which reads every word
and never gets bored. A person skims, decides, and leaves. So the test for a
line here is not *is it true* — most of what should be cut is true — but
**does the reader still need it to decide**: whether to use this, whether to
contribute, where to send a vulnerability.

Say each thing once. Keep one example; the second is the first with different
nouns. State the number and drop the argument for it.

Little of what goes should be deleted — it is in the wrong place, not too
long. Reasoning and rejected alternatives belong in `docs/decisions/`, how to
do a thing in `docs/how-to/` or a skill, what a script does in its own
docstring.
